# Бетс Telegram Mini App

Telegram Mini App для платформы Бетс с функционалом профиля, баланса, инвентаря и калькулятора.

## Функционал

- ✅ Авторизация через Telegram
- ✅ Уникальный ID пользователя в системе
- ✅ Вкладка Profile с балансом и инвентарем
- ✅ Вкладки Promocodes, Referrals, Stacking
- ✅ Калькулятор с операциями +, -, ×, ○ (сброс)
- ✅ Уведомления через Toast
- ✅ Адаптивный дизайн под мобильные устройства
- ✅ Сохранение данных в localStorage

## Развертывание на Vercel

### Способ 1: Через GitHub

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы проекта
3. Зайдите на [Vercel](https://vercel.com)
4. Нажмите "Add New..." → "Project"
5. Импортируйте репозиторий
6. Настройки оставьте по умолчанию
7. Нажмите "Deploy"
